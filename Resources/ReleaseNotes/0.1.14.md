# xiaoai-archive 0.1.14

Local fork build 27. A signed automatic update feed has not been published.

## Improvements
- Rename the app, sharing entries, and offline preview to xiaoai-archive.
- Point source, maintainer, and release links to luoluo-sen/xiaoai-archive.
- Check this repository's latest stable GitHub Release and report its version.
- Read the loaded conversation names from the current regular or folded WeChat list.
- Preserve existing archives and preferences during the product rename.
- Pin a local signing certificate and reject incompatible updates before replacing the installed app.
- Require an enabled sharing entry before completing first-run setup and explain the entry needed for quick WeChat forwarding.

## Fixes
- Remove the extra empty settings window.
- Use the same `~/Downloads/xiaoai-archive/Inbox/` directory in the app and all five share extensions, removing the old App Group and Application Support inbox split.
- Give the share extensions macOS Downloads read/write access so file handoff no longer depends on the original developer's team.
- Show the selected message count after selection and an explicit waiting-for-export status while receiving files.
- Report an unavailable inbox or a newly received share failure directly instead of reporting every failure as a timeout.

## Validation
- Compilation, packaging, all five extension signatures, configuration, and Chinese/English localization checks passed. The installed main app can watch the new inbox and retains Accessibility authorization.
- Actual WeChat export, extension file receipt, and final ZIP saving still require manual verification by the user; end-to-end success is not claimed.
