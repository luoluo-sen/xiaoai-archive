# xiaoai-archive 0.1.14

本地分支构建 28。当前尚未发布签名自动更新源。

## 改进
- 群内实际消息少于设定条数时，定位到最早一条可用消息并按实际条数导出，该群记为成功，批量继续后面的群，不再报「未能读到范围起点」。
- 消息条数输入 0 表示导出该群从第一条到最新的全部消息，按每 100 条分批导出到会话开头；仅在确认已到会话真正顶部（而非仍在加载更早记录）时按实际条数完成。
- 支持勾选当前已加载的多个会话进行串行批量转发，统一条数可被单群条数覆盖。
- 支持每群独立进度和结果，失败暂停，用户主动继续时跳过已完成群聊；每群独立归档。
- 应用、分享入口和离线预览统一更名为 xiaoai-archive。
- 源码、维护者和发行版本链接指向 luoluo-sen/xiaoai-archive。
- 查询本仓库最新正式 GitHub Release，比较并显示版本号。
- 读取当前微信普通或折叠列表中已加载的会话名称。
- 更名后继续使用已有归档和设置。
- 固定本机签名证书，覆盖安装前拒绝签名不兼容的更新。
- 首次设置需启用分享入口，说明快捷微信转发所需入口，避免未配置就显示完成。

## 修复
- 移除多余的空白设置窗口。
- 主程序和五个分享扩展统一使用 `~/Downloads/xiaoai-archive/Inbox/`，移除旧 App Group 和 Application Support 收件箱分叉。
- 分享扩展使用系统下载目录读写权限，文件交接不再依赖原作者的开发团队。
- 微信选完消息后显示实际选中条数，等待文件时明确显示“正在等待微信导出文件”。
- 收件箱未就绪或收到本次分享的失败报告时显示真实错误，不把这些情况一律拖到超时。

## 验证状态
- 编译、打包、五个分享扩展签名、配置和中英文文案检查通过；本机主程序已能监视新收件箱，辅助功能授权仍有效。
- 微信真实导出、分享扩展写入及最终 ZIP 保存仍待用户手动验证，不声明已完成端到端验证。
